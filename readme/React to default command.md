
By default this project will fire Tasker command if no action is assigned.


&nbsp;


# Default Command

The default command has this pattern.

```bsh
Every=:=[Handle name]=:=[Gesture Name]=:=[Long Press or not]=:=[Info json]
```

1. **Handle name** is the handle where the gesture is initiated. e.g Right Middle.
2. **Gesture name** is the name of the gesture. e.g up, down, left.
3. **Long press** is a boolean value. `true` for long press `false` for quick release.
4. **Json Info** is information about the gesture performed.


The json info can be inspected by clicking the toast sample profile shows.

&nbsp;

# Reacting to default command

To react to the default behaviour, we have to use **Event > Tasker > Command** context.

With the following configuration for each fields.

### Command Field
Use the default command pattern as reference. Ideally we want something simple like this.

```
Every=:=[Handle name]=:=[Gesture Name]=:=[Long Press or not]=:=*
```

&nbsp;

Example, performing "up" gesture on a handle name "Right Middle".

```
Every=:=Right Middle=:=up=:=*
```
&nbsp;

> [!TIP]
> Use helper mode to automatically fill necessary fields. [Check it out here.](/readme/Helper%20mode.md)

&nbsp;

### Variables Field
Variables are optional but just in case we want to intercept the variables and use it in the task.

This respect Tasker command system, which we can read about the rules here.

https://tasker.joaoapps.com/commandsystem.html

However we can just use the following format.
```
%handle,%gesture,%longpress,%info
```

This will generate all the information passed by the command itself as variables.

&nbsp;

> [!TIP]
> Add a new Java code action and run `everyGesture.inspectVariables(tasker)` to inspect the variables generated by the command.
